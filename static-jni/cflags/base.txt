# Extra C flags appended to every static-archive translation unit across both
# netty and netty-tcnative, on EVERY platform and target. One flag per line;
# blank lines and `#`-comment lines are ignored.
#
# Read by scripts/stage-natives.sh and scripts/stage-natives-tcnative.sh,
# threaded into Makefile.static via the USER_CFLAGS make variable.
#
# Sibling files in this directory layer on top of base.txt:
#   linux.txt / darwin.txt / openbsd.txt / freebsd.txt / windows.txt — per-OS
#   amd64.txt / arm64.txt / riscv64.txt                               — per-arch
# The script picks the matching OS and arch file based on the build profile;
# all matching files are concatenated in order: base → os → arch.

-flto=thin
-ffunction-sections
-fdata-sections
-fstack-protector-strong
-fexperimental-relative-c++-abi-vtables
# Linux-only flags (-fbasic-block-sections=all, -fstack-clash-protection)
# live in cflags/linux.txt — Apple's clang rejects them on darwin.
#
# Polly is a clang LLVM plugin that ships with neither Alpine's clang22 nor
# Apple's clang. Re-enable in a host-specific cflags/<os>.txt only when the
# host has a custom clang built with -DLLVM_ENABLE_PROJECTS="...polly...".
# -mllvm
# -polly
